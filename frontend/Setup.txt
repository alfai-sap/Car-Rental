================================================================================
            Car Rental Management System — Frontend Setup Guide
================================================================================

PREREQUISITES
-------------
- Node.js >= 22.12.0 (recommended) or Node.js 22.11.0 with Vite 5
- npm 10+


PROJECT STRUCTURE
-----------------
frontend/
├── index.html               # Vite entry HTML
├── package.json             # Dependencies & scripts
├── vite.config.ts           # Vite + Vue + Tailwind plugins
├── tsconfig.json            # TypeScript configuration
├── src/
│   ├── main.ts              # Inertia.js + Pinia initialization
│   ├── style.css            # Tailwind CSS import
│   ├── App.vue              # Root Vue component (handled by Inertia)
│   ├── pages/               # Inertia page components
│   │   ├── Home.vue
│   │   └── About.vue
│   ├── components/          # Reusable Vue components
│   └── assets/              # Static assets


================================================================================
                        CRITICAL: VERSION COMPATIBILITY
================================================================================

The following versions MUST match exactly as shown. Using wrong versions
will cause "rolldown native binding" errors or Inertia.js protocol mismatches.

| Package               | Version     | Why                                    |
|-----------------------|-------------|----------------------------------------|
| vite                  | ^5.x        | Vite 6 requires Node >= 22.12.0        |
| @vitejs/plugin-vue    | ^5.x        | Must match Vite major version           |
| @inertiajs/vue3       | ~1.2.0      | MUST match inertia-django protocol      |
| pinia                 | ^4.x        | State management                       |
| tailwindcss           | ^4.x        | CSS framework                          |
| @tailwindcss/vite     | ^4.x        | Vite plugin for Tailwind v4            |
| vue                   | ^3.5.x      | Vue 3 framework                        |

DO NOT install @inertiajs/vue3 v2 or v3 — they are incompatible
with inertia-django v1.2.0 and will produce:
  TypeError: Cannot read properties of null (reading 'component')

DO NOT install Vite 6 with Node.js < 22.12.0 — rolldown native bindings
will fail to install with:
  Error: Cannot find native binding


1. SCAFFOLD THE VUE + VITE + TYPESCRIPT PROJECT
-----------------------------------------------
From the project root (Car-Rental/):

    npm create vite@latest frontend -- --template vue-ts

If the interactive prompt appears instead of scaffolding directly,
cancel (Ctrl+C) and run:

    npx create-vite@latest frontend --template vue-ts


2. ENTER THE FRONTEND DIRECTORY
-------------------------------
    cd frontend


3. PIN VITE TO VERSION 5
------------------------
Vite 6+ requires Node.js >= 22.12.0. Pin to Vite 5 for stability:

    npm install vite@5 @vitejs/plugin-vue@5


4. INSTALL PROJECT DEPENDENCIES
-------------------------------
Install exact versions to avoid compatibility issues:

    npm install @inertiajs/vue3@1.2.0 pinia
    npm install -D tailwindcss @tailwindcss/vite

Verify package.json contains:
    "@inertiajs/vue3": "^1.2.0"    (NOT ^2.x or ^3.x)
    "vite": "^5.x"                  (NOT ^6.x)


5. CONFIGURE TAILWIND CSS
-------------------------
Edit vite.config.ts:

    import { defineConfig } from 'vite'
    import vue from '@vitejs/plugin-vue'
    import tailwindcss from '@tailwindcss/vite'

    export default defineConfig({
      plugins: [vue(), tailwindcss()],
    })

Edit src/style.css — replace ALL content with:

    @import "tailwindcss";


6. CONFIGURE INERTIA.JS (main.ts)
---------------------------------
Replace src/main.ts with:

    import { createApp, h } from 'vue'
    import { createInertiaApp } from '@inertiajs/vue3'
    import { createPinia } from 'pinia'

    createInertiaApp({
      resolve: (name) => {
        const pages: Record<string, () => Promise<unknown>> = {
          Home: () => import('./pages/Home.vue'),
          About: () => import('./pages/About.vue'),
        }
        const loader = pages[name] || pages['Home']
        return loader()   // CALL the function, don't return it directly
      },
      setup({ el, App, props, plugin }) {
        const app = createApp({ render: () => h(App, props) })
        app.use(plugin)
        app.use(createPinia())
        app.mount(el)
      },
    })

Important: pages[name] returns a function. You MUST call it: pages[name]()
Returning the function without calling it causes Inertia to fail silently.


7. CREATE PAGE COMPONENTS
-------------------------
Create the pages directory:

    mkdir src\pages

Create src/pages/Home.vue:

    <template>
      <div class="flex min-h-screen items-center justify-center bg-gray-100">
        <div class="text-center">
          <h1 class="text-3xl font-bold text-gray-800">Car Rental</h1>
          <p class="mt-2 text-gray-600">{{ message || 'Welcome' }}</p>
        </div>
      </div>
    </template>

    <script setup lang="ts">
    defineProps<{ message?: string }>()
    </script>

Create src/pages/About.vue:

    <template>
      <div class="flex min-h-screen items-center justify-center bg-gray-100">
        <div class="text-center">
          <h1 class="text-3xl font-bold text-gray-800">About Us</h1>
          <p class="mt-2 text-gray-600">{{ title || 'Car Rental Management' }}</p>
        </div>
      </div>
    </template>

    <script setup lang="ts">
    defineProps<{ title?: string }>()
    </script>


8. CLEAN UP BOILERPLATE
-----------------------
    Remove-Item src\components\HelloWorld.vue -Force -ErrorAction SilentlyContinue
    Remove-Item src\assets\vue.svg -Force -ErrorAction SilentlyContinue


9. START THE DEV SERVER
-----------------------
    npm run dev

Starts at: http://localhost:5173/

The page will show an Inertia error at this stage — this is expected.
Inertia needs the Django backend to supply page data via the data-page
attribute. Proceed to the backend Setup.txt for Django integration.


10. FULL-STACK: DJANGO + INERTIA INTEGRATION
--------------------------------------------
Once both frontend and backend are set up:

Terminal 1 — Django (port 8000):
    cd backend
    .\.venv\Scripts\Activate.ps1
    python manage.py runserver

Terminal 2 — Vite (port 5173):
    cd frontend
    npm run dev

Open: http://127.0.0.1:8000/

TROUBLESHOOTING
---------------
| Issue                                   | Solution                                      |
|-----------------------------------------|-----------------------------------------------|
| "Cannot find native binding" (rolldown) | Downgrade Vite to v5 (see Step 3)              |
| "Cannot read properties of null         | @inertiajs/vue3 version mismatch.              |
|  (reading 'component')"                 | Install v1.2.0: npm install @inertiajs/vue3@1.2.0|
|                                         | Clear Vite cache and restart                   |
| Vite shows old code after changes       | Clear Vite cache: Remove-Item -Recurse -Force  |
|                                         | node_modules/.vite; restart Vite               |
| Inertia resolve returns null            | Ensure loader() is CALLED, not returned as fn  |
| TemplateDoesNotExist at /               | INERTIA_LAYOUT = 'base.html' (include .html)   |
| Tailwind styles not applying            | @import "tailwindcss" must be in style.css     |
