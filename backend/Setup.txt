================================================================================
            Car Rental Management System — Backend Setup Guide
================================================================================

PREREQUISITES
-------------
- Python 3.11+
- PostgreSQL 17+
- pip (Python package manager)


PROJECT STRUCTURE
-----------------
backend/
├── .venv/                  # Python virtual environment
├── .env                    # Environment variables (DB, SECRET_KEY, DEBUG)
├── requirements.txt        # Python dependencies
├── manage.py               # Django management script
├── config/                 # Django project settings
│   ├── settings.py         # PostgreSQL, apps, static/media, auth config
│   ├── urls.py             # Root URL routing
│   ├── wsgi.py             # WSGI entry point
│   └── asgi.py             # ASGI entry point
├── apps/                   # Django applications
│   ├── core/               # Shared utilities & base models
│   ├── accounts/           # Custom User model (AbstractUser) + auth
│   ├── vehicles/           # Vehicle management
│   ├── bookings/           # Booking management
│   ├── payments/           # Payment integration (PayMongo)
│   └── reports/            # Reports & analytics
├── static/                 # Static files (CSS, JS, images)
├── media/                  # User-uploaded files (vehicle images)
└── templates/              # Django HTML templates


1. CREATE THE DATABASE
----------------------
Open a terminal and run:

    psql -U postgres

Then execute:

    DROP DATABASE IF EXISTS car_rental;
    CREATE DATABASE car_rental;
    \q


2. CONFIGURE ENVIRONMENT (.env)
-------------------------------
Create or edit backend/.env with the following:

    # Django
    SECRET_KEY=django-insecure-change-me-in-production
    DEBUG=True
    ALLOWED_HOSTS=localhost,127.0.0.1

    # PostgreSQL
    DB_NAME=car_rental
    DB_USER=postgres
    DB_PASSWORD=your_postgres_password
    DB_HOST=localhost
    DB_PORT=5432

Replace your_postgres_password with your actual PostgreSQL password.


3. SET UP VIRTUAL ENVIRONMENT & INSTALL DEPENDENCIES
----------------------------------------------------
From the backend/ directory:

    python -m venv .venv
    .\.venv\Scripts\Activate.ps1          # Windows PowerShell
    pip install -r requirements.txt


   Installed packages:
   - Django 5.2.17          (Web framework)
   - psycopg2-binary 2.9.12 (PostgreSQL adapter)
   - python-decouple 3.8    (Environment variable management)
   - Pillow 12.3.0          (Image handling)


4. RUN DATABASE MIGRATIONS
--------------------------
    python manage.py makemigrations accounts
    python manage.py migrate


5. CREATE A SUPERUSER (Admin)
-----------------------------
    python manage.py createsuperuser

   Or use the non-interactive shortcut:

    $env:DJANGO_SUPERUSER_PASSWORD="admin123"
    $env:DJANGO_SUPERUSER_EMAIL="admin@carrental.com"
    python manage.py createsuperuser --username admin --noinput


6. START THE DEVELOPMENT SERVER
-------------------------------
    python manage.py runserver

   The server starts at: http://127.0.0.1:8000/
   Admin panel:          http://127.0.0.1:8000/admin/


7. VERIFY THE SETUP
-------------------
    # Check for configuration errors
    python manage.py check

    # Verify database tables
    psql -U postgres -d car_rental -c "\dt"


QUICK START (ALL-IN-ONE)
------------------------
If the virtual environment is already set up:

    cd backend
    .\.venv\Scripts\Activate.ps1
    python manage.py migrate
    python manage.py runserver


TROUBLESHOOTING
---------------
| Issue                          | Solution                                    |
|--------------------------------|---------------------------------------------|
| "role postgres does not exist" | Create the PostgreSQL user or use your own  |
| "database already exists"      | Drop it first: DROP DATABASE car_rental;    |
| "password authentication failed"| Check DB_PASSWORD in .env                  |
| "port 8000 already in use"     | Use a different port: runserver 0.0.0.0:8080|
| "No module named decouple"     | Run: pip install python-decouple            |


================================================================================
            Car Rental Management System — Frontend Setup Guide
================================================================================

PREREQUISITES
-------------
- Node.js >= 22.12.0 (OR use Vite 5 for Node.js 22.11.0 and older)
- npm 10+


PROJECT STRUCTURE
-----------------
frontend/
├── index.html               # Vite entry HTML
├── package.json             # Dependencies & scripts
├── vite.config.ts           # Vite + Vue + Tailwind plugins
├── tsconfig.json            # TypeScript configuration
├── src/
│   ├── main.ts              # Inertia.js + Pinia initialization
│   ├── style.css            # Tailwind CSS import
│   ├── App.vue              # Root Vue component (unused by Inertia)
│   ├── pages/               # Inertia page components
│   │   ├── Home.vue
│   │   └── About.vue
│   ├── components/          # Reusable Vue components
│   └── assets/              # Static assets


IMPORTANT: VERSION COMPATIBILITY
--------------------------------
The following versions MUST match. Using wrong versions will cause
"rolldown native binding" or "Cannot read properties of null" errors.

| Package               | Version  | Why                                   |
|-----------------------|----------|---------------------------------------|
| vite                  | ^5.x     | Stable — no rolldown native binding   |
| @vitejs/plugin-vue    | ^5.x     | Matches Vite 5                        |
| @inertiajs/vue3       | ~1.2.0   | MUST match inertia-django v1.2.0      |
| pinia                 | ^4.x     | State management                      |
| tailwindcss           | ^4.x     | CSS framework                         |
| @tailwindcss/vite     | ^4.x     | Vite plugin for Tailwind v4           |
| vue                   | ^3.5.x   | Vue 3 framework                       |

⚠️  DO NOT install @inertiajs/vue3 v2 or v3 — they are incompatible
   with inertia-django v1.2.0 and will cause a blank page with the error:
   "Cannot read properties of null (reading 'component')"

⚠️  DO NOT install Vite 6+ with Node.js < 22.12.0 — it requires rolldown
   native bindings that fail to install on older Node versions.


1. SCAFFOLD THE PROJECT
-----------------------
From the project root (Car-Rental/):

    npm create vite@latest frontend -- --template vue-ts

   If prompted to install create-vite, press y.
   If the interactive prompt appears, cancel (Ctrl+C) and run:

    npx create-vite@latest frontend --template vue-ts


2. ENTER THE FRONTEND DIRECTORY
-------------------------------
    cd frontend


3. PIN VITE TO VERSION 5 (Critical Step)
-----------------------------------------
Vite 6+ uses rolldown which requires Node.js >= 22.12.0 and fails
on older versions with "Cannot find native binding" errors.

    npm install vite@5 @vitejs/plugin-vue@5


4. INSTALL PROJECT DEPENDENCIES
-------------------------------
Install the remaining packages with exact compatible versions:

    npm install @inertiajs/vue3@1.2.0 pinia
    npm install -D tailwindcss @tailwindcss/vite

   Full dependency list at this point:
   - vue 3.5.x              (Framework)
   - vite 5.x               (Build tool)
   - @vitejs/plugin-vue 5.x (Vue SFC compiler)
   - @inertiajs/vue3 1.2.0  (Inertia adapter — MUST be v1.x)
   - pinia 4.x              (State management)
   - tailwindcss 4.x        (CSS framework)
   - @tailwindcss/vite 4.x  (Tailwind Vite plugin)


5. CONFIGURE TAILWIND CSS
-------------------------
Edit vite.config.ts:

    import { defineConfig } from 'vite'
    import vue from '@vitejs/plugin-vue'
    import tailwindcss from '@tailwindcss/vite'

    export default defineConfig({
      plugins: [vue(), tailwindcss()],
    })

Edit src/style.css — replace all content with:

    @import "tailwindcss";


6. CONFIGURE INERTIA.JS (main.ts)
---------------------------------
Replace src/main.ts with:

    import { createApp, h } from 'vue'
    import { createInertiaApp } from '@inertiajs/vue3'
    import { createPinia } from 'pinia'

    createInertiaApp({
      resolve: (name) => {
        const pages: Record<string, () => Promise<unknown>> = {
          Home: () => import('./pages/Home.vue'),
          About: () => import('./pages/About.vue'),
        }
        const loader = pages[name] || pages['Home']
        return loader()  // MUST call the function, not return it
      },
      setup({ el, App, props, plugin }) {
        const app = createApp({ render: () => h(App, props) })
        app.use(plugin)
        app.use(createPinia())
        app.mount(el)
      },
    })

   ⚠️  CRITICAL: In the resolve function, call loader() to return
   a Promise. Returning the function without calling it (pages[name])
   will cause Inertia to receive a function instead of a component.


7. CREATE PAGE COMPONENTS
-------------------------
Create the pages directory and starter pages:

    mkdir src\pages

Create src/pages/Home.vue:

    <template>
      <div class="flex min-h-screen items-center justify-center bg-gray-100">
        <div class="text-center">
          <h1 class="text-3xl font-bold text-gray-800">Car Rental</h1>
          <p class="mt-2 text-gray-600">{{ message || 'Welcome' }}</p>
        </div>
      </div>
    </template>

    <script setup lang="ts">
    defineProps<{ message?: string }>()
    </script>

Create src/pages/About.vue:

    <template>
      <div class="flex min-h-screen items-center justify-center bg-gray-100">
        <div class="text-center">
          <h1 class="text-3xl font-bold text-gray-800">About Us</h1>
        </div>
      </div>
    </template>

    <script setup lang="ts">
    defineProps<{ title?: string }>()
    </script>


8. CLEAN UP BOILERPLATE
-----------------------
    Remove-Item src\components\HelloWorld.vue -Force -ErrorAction SilentlyContinue
    Remove-Item src\assets\vue.svg -Force -ErrorAction SilentlyContinue


9. START THE DEVELOPMENT SERVER
-------------------------------
    npm run dev

   The server starts at: http://localhost:5173/

   NOTE: The page will show "Cannot read properties of null" at this
   stage — this is expected. Inertia requires the Django backend to
   supply the initial page data. Proceed to connect Django via Inertia.


10. CONNECT DJANGO (BACKEND SIDE)
---------------------------------
Ensure these are set up in the Django backend (already done if
following the backend guide above):

   a) Install inertia-django:
      pip install inertia-django==1.2.0

   b) In config/settings.py:
      INSTALLED_APPS = [
          ...
          'inertia',
          ...
      ]
      MIDDLEWARE = [
          ...
          'inertia.middleware.InertiaMiddleware',
          ...
      ]
      INERTIA_VERSION = '1.0'
      INERTIA_LAYOUT = 'base.html'

   c) Create templates/base.html (loads Vite dev server):

      <!DOCTYPE html>
      <html lang="en">
      <head>
          <meta charset="UTF-8">
          <meta name="viewport" content="width=device-width, initial-scale=1.0">
          <title>Car Rental</title>
          <script type="module" src="http://localhost:5173/@vite/client"></script>
          <script type="module" src="http://localhost:5173/src/main.ts"></script>
      </head>
      <body>
          {% block inertia %}{% endblock %}
      </body>
      </html>

   d) In apps/core/views.py, use Inertia's render:
      from inertia import render

      def home(request):
          return render(request, 'Home', {
              'message': 'Welcome to Car Rental',
          })

   e) Wire up URLs and start both servers.


11. RUN THE FULL STACK
----------------------
Terminal 1 — Django:
    cd backend
    .\.venv\Scripts\Activate.ps1
    python manage.py runserver

Terminal 2 — Vite:
    cd frontend
    npm run dev

Open http://127.0.0.1:8000/ in the browser.
The "Welcome to Car Rental" page should render via Inertia.


TROUBLESHOOTING
---------------
| Issue                                    | Solution                                         |
|------------------------------------------|--------------------------------------------------|
| "Cannot find native binding" (rolldown)  | Pin vite@5. Delete node_modules & package-lock,  |
|                                          | npm install vite@5 @vitejs/plugin-vue@5, then    |
|                                          | npm install                                      |
| "Cannot read properties of null          | @inertiajs/vue3 version mismatch. Use v1.2.0:    |
|  (reading 'component')"                  | npm install @inertiajs/vue3@1.2.0                |
|                                          | Remove-Item -Recurse -Force node_modules/.vite   |
|                                          | Restart Vite dev server                          |
| Inertia page not found / blank page      | Ensure pages[name]() is CALLED in resolve(),     |
|                                          | not returned as a function. See Section 6.       |
| TemplateDoesNotExist at /                | INERTIA_LAYOUT must include .html extension:     |
|                                          | INERTIA_LAYOUT = 'base.html'                     |
| Vite shows old code after npm install    | Clear Vite cache:                                |
|                                          | Remove-Item -Recurse -Force node_modules/.vite   |
|                                          | Restart Vite (Ctrl+C, then npm run dev)          |
| Tailwind classes not applying            | Ensure @import "tailwindcss" is in style.css     |
|                                          | and tailwindcss/vite plugin is in vite.config.ts |
| Port 5173 already in use                 | Vite auto-increments to 5174, 5175, etc.         |
