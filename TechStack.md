# Why This Stack?

## Vue 3

A modern, lightweight frontend framework with an excellent developer experience.

---

## TypeScript

Improves maintainability through static typing, better editor support, and fewer runtime errors.

---

## Vite

Provides fast development startup, hot module replacement, and optimized production builds.

---

## Vue Router

Handles client-side navigation, enabling a seamless single-page application experience.

---

## Pinia

Manages shared application state, such as authentication, user information, theme preferences, and booking data.

---

## Axios

Simplifies communication with the Django REST API through a clean and consistent HTTP client.

---

## Tailwind CSS

Enables rapid development of a clean, responsive, and maintainable user interface.

---

## shadcn-vue

Provides accessible, customizable UI components that align with the project's minimalist design philosophy.

---

## Lucide Vue

Offers a lightweight, consistent icon library that complements the overall design system.

---

## Django

A mature backend framework with strong security defaults, excellent documentation, and robust support for business applications.

---

## Django REST Framework

Provides a structured and scalable REST API for communication between the frontend and backend.

---

## PostgreSQL

A reliable, high-performance relational database suitable for transactional systems such as booking and payment platforms.

---

## JWT Authentication

Supports secure, stateless authentication between the Vue frontend and Django backend.

---

## PayMongo

Provides local payment methods commonly used in the Philippines, including credit cards, debit cards, and GCash.

---
